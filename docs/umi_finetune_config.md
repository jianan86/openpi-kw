方案 B：大数据量（500+ 个 Episode，接近原版 UMI 规模）—— “ViT 全量微调 + VLM 冻结” 策略训练配置：ViT（视觉）：完全解冻（Full Fine-tuning），让海量的 UMI 数据把视觉特征彻底重塑为对鱼眼敏感的空间表示。VLM（语言）：彻底冻结（Fully Frozen）。在 openpi 配置或 LeRobot 中设置 train_expert_only=true 的变体（但单独在代码中把视觉部分排除在冻结列表之外）。Action Head：完全放开。优势：最大化发挥大数据的端到端威力。由于 VLM 被冻结，显存开销被转嫁给了 ViT，模型在大规模数据下对鱼眼和复杂机械臂轨迹的收敛效果最好。总结建议如果你打算使用 openpi 或 LeRobot 框架 启动训练：请先检查 freeze_filter 配置文件。保持 Action Head 开、ViT 开。将 Gemma/LLM 主干 设为全冻结或LoRA 模式。特别提醒：解冻 ViT 后，学习率（Learning Rate）一定要调得足够小（例如 1e-5 甚至 5e-6），并搭配层级学习率衰减（Layer-wise LR Decay），否则鱼眼带来的巨大视觉梯度冲击可能会直接把整个模型的权重调崩。
